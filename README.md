# 🤖 AI 미국 주식 자동 추천 & 리스크 관리 코파일럿 (US Stock AI Copilot)

> **"컴퓨터를 켜두지 않아도 매일 밤 GitHub Actions가 시장과 종목을 전수 분석하여, 디스코드로 최적의 종목과 추천 금액·손절선을 브리핑합니다."**

---

## 📌 시스템 핵심 아키텍처

1. **글로벌 매크로 & 안전장치 (Safety Switch)**
   - VIX 공포지수, S&P 500 200일선 추세, 미국 10년물 국채 금리 모니터링
   - 폭락장 또는 VIX 급등 시 신규 매수 차단 및 현금 90~100% 보존 모드 자동 가동
   - **실적 발표(Earnings) 폭탄 방지**: 5일 이내 실적 발표 예정인 종목 자동 제외

2. **🥊 1단계: 모델 토너먼트 리그전 (Model Competition)**
   - **Model A [모멘텀 돌파형 (LightGBM)]**: 신고가 근접, 수급/거래량 급증 추세추종
   - **Model B [우량주 눌림목 반등형 (GBM)]**: 200일선 우상향 우량주 중 단기 눌림목 포착
   - **Model C [안정형 정배열 추세 (Multi-Factor)]**: 이평선 정배열(20>50) 및 변동성 안정형
   - **리그전 리더보드**: 샤프 지수, 승률, MDD를 실시간 채점하여 매일 1위 챔피언 모델 선출
   - **만장일치(Consensus) 종목**: 여러 모델이 동시에 지목한 종목에 최고 가중치 부여

3. **🧠 2단계: 강화학습(RL) 펀드매니저 (자금 & 비중 최적화)**
   - 매크로 위험도와 ML 후보 점수를 기반으로 **최적 현금 비중(%) 및 종목별 투자 금액($)** 동적 배분
   - 1종목 최대 투자 한도(15%) 제한으로 리스크 분산

4. **📢 디스코드 스마트 브리핑**
   - 매일 미국 장 개장 전 디스코드 채널로 리포트 카드(Embed) 전송
   - 트레이딩뷰 차트 1초 바로가기 링크 제공
   - 진입가, AI 추천 금액/주수, 칼손절선(-2.5%), 목표가 명시

## ⚙️ 빠른 시작 가이드 (Local)

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 디스코드 웹훅 설정 (1분 소요)
1. 디스코드 서버 내 알림을 받을 채널 설정 → **[연동]** → **[웹후크 만들기]** → **[웹후크 URL 복사]**
2. 프로젝트 루트의 `.env` 파일에 복사한 URL 붙여넣기:
```env
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/your_webhook_id/your_token
```

### 3. 로컬 1회 테스트 실행
```bash
# 기본 10,000달러 기준 실행
python main.py --budget 10000

# 내 자산이 5,000달러일 때
python main.py --budget 5000
```

## ☁️ 내 컴퓨터 끄고 100% 무료 자동화 (GitHub Actions)

집 컴퓨터를 24시간 켜둘 필요 없이, GitHub Actions가 매일 밤 클라우드에서 대신 실행합니다.

1. 이 프로젝트 코드를 본인의 **GitHub 비공개(Private) 저장소**에 Push합니다.
2. GitHub 저장소의 **Settings** → **Secrets and variables** → **Actions** 이동.
3. **[New repository secret]** 클릭:
   - Name: `DISCORD_WEBHOOK_URL`
   - Value: 디스코드 웹후크 URL 붙여넣기
4. **끝!**
   - 매일 평일 미국 장 개장 전(한국 시간 밤 22:30) 자동으로 분석 후 디스코드로 알림이 옵니다.
   - GitHub 웹사이트나 스마트폰 GitHub 앱의 **Actions** 탭에서 **[Run workflow]**를 눌러 언제든 즉시 수동 실행할 수도 있습니다.
