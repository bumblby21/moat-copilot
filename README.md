# Moat Copilot - AI US Stock Value & Economic Moat Investing System

워런 버핏의 경제적 해자(Economic Moat) 철학과 퀀트 알고리즘을 결합한 미국 주식 자동화 투자 코파일럿 시스템입니다.

---

## 1. 시스템 핵심 철학 및 아키텍처

### 투자 철학: 경제적 해자와 안전마진
- **ROE (자기자본이익률) 15% 이상**: 주주 자본을 효율적으로 굴려 지속적인 초과수익을 내는 1등 독점 기업 선별
- **영업이익률 10% 이상**: 강력한 브랜드 파워와 가격 결정력을 갖춘 고마진 비즈니스
- **안전마진 (Margin of Safety)**: 52주 최고점 대비 최소 -8.0% 이상 할인된 바겐세일 구간에서만 신규 추천
- **엄격한 스크리닝 원칙**: 위 4대 기준을 통과하지 못하는 종목은 시장이 고평가 상태인 것으로 판단하여 억지 추천을 배제하고 100% 현금 보존 권장

### 3단계 역할 분담 체계
1. **신규 매수 (인간의 결정권)**: `!추천` 브리핑과 3단 멀티 차트를 확인한 뒤, 사용자가 디스코드 버튼을 눌러 투자 금액과 진입 가격을 설정 및 승인
2. **스마트 물타기 (AI 100% 자동 집행)**: 보유 종목이 일시적 조정으로 진입가 대비 -10%, -18% 하락 시 AI가 자동으로 60달러씩 분할 매수 집행 및 사후 알림 전송
3. **매도 및 익절 (AI 100% 기계적 집행)**: 목표가(+15.0%) 도달 시 AI가 고점에서 전량 자동 익절 매도하여 확정 수익 회수

---

## 2. 스마트 물타기 5대 안전 방지책 (Guardrails)

비이성적 물타기로 인한 계좌 침몰을 원천 차단하기 위해 5중 하드캡이 적용되어 있습니다.

1. **종목당 최대 2회 절대 캡 (Hard Count)**: 1차(-10%), 2차(-18%)까지만 매수하며 3차 이상 추가 매수는 시스템상 완전 차단
2. **종목당 총 투자액 상한선 (250달러 캡)**: 단일 종목 총 투자액이 전체 계좌 자산(1,000달러 기준)의 25%를 초과하지 못하도록 제한
3. **비상 현금 보존 버퍼 (100달러 유지)**: 가용 현금이 100달러 이하로 떨어질 경우 모든 물타기 집행 자동 일시 중지
4. **3일 쿨다운 (Cooldown Period)**: 단기 폭락 시 떨어지는 칼날을 잡지 않고, 최초 매수일 또는 직전 물타기일로부터 최소 3일간 바닥 다지기를 확인한 후 집행
5. **펀더멘털 해자 수호 (ROE 15%+)**: 주가 하락 원인이 본업 훼손(ROE 15% 미만 추락) 때문일 경우 물타기를 즉시 금지하고 전량 기계적 손절 집행

---

## 3. 3단 멀티 분석 차트 (3M / 1Y / 5Y)

- **상단 패널**: 최근 3개월 (3M) 단기 가격 흐름 및 일일 거래량 (단기 바닥 및 매수세 유입 확인)
- **중간 패널**: 최근 1년 (1Y) 중기 안전마진 추세 및 52주 고점/저점 범위 (최근 1년 할인율 확인)
- **하단 패널**: 5년 (5Y) 장기 경제적 해자 성장 궤적 및 역사적 밸류에이션 채널 (기업 성장 지속성 확인)

## 4. 디스코드 명령어 가이드

### 종목 분석 및 추천
- `!추천` : 버핏 30대 해자 기업 스크리닝, 3단 멀티 차트, 원클릭 매수 버튼 제공 (이미 보유한 종목은 자동 제외)
- `!차트` : 원하는 기업의 3개월/1년/5년 3단 종합 차트 생성

### 주문 및 계좌 관리
- `!매수` : 원하는 종목 선택 후 투자금액 및 진입 희망가 팝업 설정
- `!물타기` : B안(-10%, -18%) 자동 매수 대기 상황, 쿨다운 남은 일수, ROE 해자 상태 실시간 현황판
- `!적립` : 매주 50달러 자동 충전 일정 확인 및 수동 추가 입금
- `!잔고` : 보유 종목 실시간 체결가, 손익률, AI 목표익절가 확인
- `!초기화` : 계좌 잔고를 초기 상태(1,000달러 100% 현금)로 리셋
- `!명령어` : 도움말 안내창 출력

## 5. 실행 및 클라우드 배포 (Render 24/7)

### 로컬 환경 실행
```bash
pip install -r requirements.txt
python bot.py
```

### 필수 환경 변수 (.env)
```env
DISCORD_BOT_TOKEN=your_discord_bot_token
DISCORD_WEBHOOK_URL=your_discord_webhook_url
```

### Render 24/7 무중단 배포 설정
- **Runtime**: Python 3
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python bot.py`
- **Plan**: Free (750시간/월 무료 리필)
- **Keep-Alive**: 자체 내장 HTTP 헬스체크 웹서버(`PORT: 10000`) 탑재로 24시간 무중단 가동 지원
